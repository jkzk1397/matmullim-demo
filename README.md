# 맞물림 — 교수·학습·평가 계획서 점검 서비스

교사가 쓴 교수·학습·평가 계획서를 교육부 고시 성취기준과 경기도교육청 2026 학업성적관리 지침에 맞춰 규칙으로 점검합니다. 틀린 곳은 근거와 함께 보여 주고, 버튼 한 번에 고쳐 파일로 돌려줍니다.

- **바로 써 보기**: https://jkzk1397.github.io/matmullim-demo/
  - `?try=info`: 정보 2학년 예시 계획서를 바로 점검 화면으로 엽니다.
  - `?try=all`: 12개 교과 합본 예시를 전체 현황으로 엽니다 (두 포스터의 QR).
  - `?try=cal`: 같은 합본 예시를 수행평가 달력으로 엽니다.
- **대상**: 경기 중학교 계획서. 2015·2022 개정 중학교 성취기준 1,466개(24개 교과)와 경기도교육청 2026 지침 규칙팩을 씁니다.
- **읽는 형식**: HWP·HWPX·Word·Excel·ODT·PDF.
  - 한글·Word·Excel·ODT는 표를 병합 칸까지 격자로 펼쳐 읽습니다.
  - PDF는 글자만 읽어 성취기준 코드·문장을 점검합니다.
  - 전 교과 합본은 교과·학년별로 나눕니다.
- **학교 단위**: 같은 학년·학기 전 교과의 수행평가를 요약표 ‘평가 시기’ 칸으로 한 달력에 놓고, 같은 주에 몰린 곳을 표시합니다. 전체 보고서(위원회용)에 달력 쪽이 붙습니다.
- **여러 학교**: 파일을 한꺼번에 넣으면 경기도교육청 「평가 계획 수립 및 운영 자체점검표」 번호별 현황을 보고, 지적 전체를 CSV로 받습니다. 공개 계획서 320개를 약 2분에 읽습니다.
- **고친 파일**: HWPX·Word는 원본에서 고친 칸만 바꾼 파일로 받습니다. 그 밖의 형식은 수정 목록(txt)으로 받습니다.
- **처리 위치**: 모두 브라우저 안에서 처리합니다. 계획서 파일을 서버나 외부 AI로 보내지 않습니다(백엔드 없음, LLM 호출 없음). 앱이 네트워크로 받는 것은 앱 자체와 예시 파일뿐입니다.
- **검증**: 경기 중학교 공개 계획서 911개로 확인했습니다 → [docs/verification.md](docs/verification.md)

## 점검하는 것

| 규칙 | 내용 | 표시 |
|---|---|---|
| J4 성취기준 코드 | 괄호 누락, 오타, DB에 없는 코드, 학년에 맞지 않는 교육과정 코드 | 확인된 오류 |
| J5 성취기준 문장 | 학년에 맞지 않는 교육과정 문장, 다른 코드의 문장, 고시 원문과 다른 문장 (글자 2개 단위 유사도로 대조) | 확인된 오류 · 지침과 다름 · 확인 필요 |
| J6 성취기준–평가 연결 | 수업 계획의 성취기준이 어떤 평가와도 연결되지 않음 (정렬 맵) | 확인 필요 |
| J7 채점기준 표현 | 과제 수행률·분량·감점·지적 횟수·출석률로 쓴 채점기준 (경기 지침 지양 표현) | 지침과 다름 |
| J12 숫자 | 반영비율 합계, 만점과 반영비율, 요약표와 세부기준 만점, 평가계획과 채점기준표 배점 | 확인된 오류 · 확인 필요 |
| J13 반영비율 하한 | 수행평가·논술형 반영비율 (경기 2026 지침) | 지침과 다름 |
| J14 결시자 처리기준 | 계획서에 결시·미응시 처리 기준이 있는지 (경기 지침) | 확인 필요 |
| J15 평가 시기 | 수행평가 시기를 주 단위로 적었는지 (이해하기 28쪽), 상시·6주보다 긴 기간 | 지침과 다름 · 확인 필요 |
| J16 AI 활용 수행평가 | AI를 쓰는 수행평가에 AI 활용 기본 원칙 세 가지가 있는지 (이해하기 32쪽, 지침 12쪽) | 지침과 다름 |
| J17 계획에 넣을 내용 | 평가 목적·방침·유의사항, 성취율·성취도, 성취수준(평가기준), 정의적 능력 평가, 학적변동자, 성적처리·결과 활용 (지침 6~7쪽) | 확인 필요 |
| J18 정기시험 | 학기당 2회 이내, 1회만 보면 반영비율 50% 이하 (지침 4쪽·7쪽) | 지침과 다름 |
| 수행평가 달력 | 같은 학년 전 교과에서 같은 주에 몰린 수행평가 (지침 8쪽·12쪽, 몇 개부터인지는 학교가 정함) | 표시 |
| S5 제안 | 학생이 자기 과정을 돌아보는 기회가 평가에 있는지 묻기 | 제안 |

학년도와 학년을 보고 칸마다 적용 교육과정(2015·2022 개정)을 가립니다. 2026학년도에는 중1·2가 2022 개정, 중3이 2015 개정입니다. 지적마다 원문 위치, 근거(고시·지침 원문 또는 같은 문서 안 대조), 고치는 법이 함께 나옵니다.

## 실행

```bash
npm install
npm run dev          # http://localhost:5173
npm test             # vitest
npm run build        # dist/
npm run samples:v2   # public/samples/v2 예시 문서 다시 만들기
```

GitHub Pages: `.github/workflows/pages.yml`이 `main`에 푸시하면 테스트 → 빌드 → 배포합니다.

## 하지 않는 것

- 고등학교, 경기 외 시·도 지침(규칙팩은 경기 2026 중학교 하나)
- HWP·PDF·Excel·ODT 수정본 파일 (수정 목록만)
- 스캔 PDF처럼 글자가 그림인 문서, PDF의 표 숫자 대조
- 학교 학업성적관리규정 자동 해석 (카드에서 확인을 안내)
- 로그인, 서버 저장, LLM 호출

## 데이터 출처

- 지침: 경기도교육청 「2026학년도 중학교 학업성적관리 시행지침」, 「2026학년도 중등 학생평가 및 학업성적관리 이해하기」 (`src/domain/rulepacks.ts`, `src/domain/rules.ts`에 쪽수와 원문)
