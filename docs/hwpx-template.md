# HWPX 표 머리글 형식

맞물림은 HWPX 안의 표를 2차원 배열로 읽은 뒤, **표의 첫 행(머리글)에 있는 낱말**로 칸의 뜻을 정합니다.
한글에서 아래 머리글 그대로 표를 만들고 **파일 → 다른 이름으로 저장 → HWPX**로 저장하면 됩니다.

- 표 바로 위 문단(예: `2. 평가 개요`)은 표 제목으로 읽습니다. 없어도 됩니다.
- 머리글 낱말은 띄어쓰기·괄호를 무시하고 **포함 여부**로 찾습니다. 예: `반영 비율(%)`, `반영비율` 모두 됩니다.
- 칸 병합(같은 평가명을 세로로 합치기)은 됩니다. 가로·세로 병합 모두 병합 시작 칸의 값을 아래 칸에도 적용합니다.
- 표 안의 표(중첩 표), 그림, 수식은 읽지 않습니다.
- 성취기준 코드는 `[9정03-04]`처럼 대괄호로 적습니다. 한 칸에 여러 개를 쉼표나 띄어쓰기로 나열해도 됩니다.
- 숫자는 단위를 보고 읽습니다. `30%`는 반영비율, `30점`은 만점·배점입니다. 한 칸에 `만점 100점, 반영비율 30%`처럼 섞여 있어도 칸의 머리글에 맞는 단위만 읽습니다.

## 평가계획서

표 순서는 상관없습니다. 세 종류 표를 머리글로 구분합니다.

### 1) 학기 성취기준 표 — 머리글에 `코드`가 있고 `평가명`이 없는 표

| 영역 | 성취기준 코드 | 성취기준 |
|---|---|---|
| 데이터 | [9정02-02] | 문제 해결에 적합한 데이터를 수집하고, 목적에 맞게 구분하여 관리한다. |
| (병합) | [9정02-03] | 실생활의 데이터를 표, 다이어그램 등 다양한 형태로 구조화한다. |

- 이 표의 코드가 **정렬 맵의 행**이 됩니다.

### 2) 평가 개요 표 — 머리글에 `평가명`과 `반영`/`만점`이 있는 표

| 평가명 | 평가 방법 | 평가 시기 | 반영비율(%) | 만점(점) |
|---|---|---|---|---|
| 지필평가(기말) | 지필 | 7월 1주 | 35% | 100점 |
| 프로그래밍 프로젝트 | 수행 | 5월 2주 ~ 6월 1주 | 35% | 30점 |
| 데이터 분석 보고서 | 수행 | 4월 1주 ~ 4월 3주 | 30% | 100점 |
| 합계 |  |  | 100% |  |

- `평가 방법`(또는 `유형`, `종류`)에 `지필`이 있으면 채점기준표 짝을 요구하지 않습니다.
- `합계`·`계` 행은 건너뜁니다. 반영비율 합계는 맞물림이 직접 계산합니다.

### 3) 평가 요소 표 — 머리글에 `평가명`과 `평가요소`가 있는 표

| 평가명 | 평가요소 | 배점(점) | 성취기준 코드 |
|---|---|---|---|
| 프로그래밍 프로젝트 | 문제 분석과 알고리즘 설계 | 10 | [9정03-04] |
| (병합) | 프로그램 구현 | 10 | [9정03-06] |
| (병합) | 결과 공유와 개선 | 10 | [9정03-08], [9정05-03] |

- 평가명은 개요 표의 평가명과 같게 적습니다(띄어쓰기·`평가`/`수행평가` 낱말 차이는 무시).

## 채점기준표

머리글에 `평가요소`와 `채점기준`(또는 `수행 수준`)이 있는 표를 읽습니다. 여러 평가를 한 표에 넣어도 되고 평가마다 표를 나눠도 됩니다.

| 평가명 | 평가요소 | 성취기준 코드 | 채점기준 | 배점(점) |
|---|---|---|---|---|
| 프로그래밍 프로젝트 | 문제 분석과 알고리즘 설계 | [9정03-04] | 상(10점): … / 중(7점): … / 하(4점): … | 10 |
| (병합) | 프로그램 구현 | [9정03-06] | 상(10점): … / 중(7점): … / 하(4점): … | 10 |

- `배점`은 그 평가요소의 **최고점**입니다. 평가요소 배점을 더한 값을 평가계획의 만점과 비교합니다.
- 평가마다 표를 나누고 `평가명` 열을 빼면, 표 바로 위 문단(예: `1. 프로그래밍 프로젝트`)을 평가명으로 씁니다.
- 채점기준 칸의 글은 J7 규칙(수행률·분량·감점·지적 횟수·출석률 표현)에 씁니다.

## 예시 파일

`public/samples/`에 위 형식의 HWPX가 있습니다(`plan-error.hwpx`, `rubric-error.hwpx` 등).
이 파일은 `npm run samples`가 `src/fixtures/*/*.json`에서 만든 **최소 구조 HWPX**(zip + XML)입니다.
맞물림 파서로는 읽히지만, 서식 정보가 최소한이라 **한글(한컴오피스)에서 열리는지는 확인하지 못했습니다.**
팀에서 한글로 같은 머리글의 표를 만들어 저장한 파일로 시험해 보세요.
